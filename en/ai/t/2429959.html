WARNINGS

When working on the boot/bonnet lides, observe the following precautions:

  • When working on the hinges, take care not to damage the paintwork.
  • If a particular adjustment requires the hinges to be moved, touch up the paintwork in the hinge area.
  • Use care when working on trim components and use the specified tools correctly in order to avoid damage.

Applies to: all engines; all production periods

PRECAUTIONS

Applies to: all engines; all production periods

PRECAUTIONS

Before working on the electrical system (connectors, electrical components, wiring etc.), turn the ignition off and disconnect the battery.

Always ask a second operator to help move the covers.
