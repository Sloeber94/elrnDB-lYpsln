Follow the safety instructions (See 5040 - Precautions)

Applies to: all engines; all production periods

Removing

Refitting

Place the vehicle on a lift.

Drain the coolant ( 0010T84 coolant for air conditioning system dehydrate and recharge ).

7210E10 R.R. FRONT BUMPER

1. Release the retaining ring.

2. Extract the drier filter cartridge (2a), via the opening (2b).

Seal the housing for the drier filter cartridge using a suitable plug to prevent dampness and impurities from entering the system.

Applies to: all engines; all production periods

Refitting

Removing

Check that the drier filter cartridge is not damaged.

Replace the O-rings for the connectors.

Only use green coloured seals, resistant to R134A coolant fluid.

Lubricate the thread of the connectors using anti-freeze.

Fit the drier filter cartridge.

Fit the seal.

7210E10 R.R. FRONT BUMPER

Repressurize using coolant fluid ( 0010T84 coolant for air conditioning system dehydrate and recharge ).
