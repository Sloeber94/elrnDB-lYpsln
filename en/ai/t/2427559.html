K64 AIRBAG FAILURE WARNING LIGHT ON

Applies to: all engines; all production periods

The brake fluid warning light remains on with the handbrake not applied.

The (negative) brake fluid level signal is sent by the special sensor to the Body Computer Node which makes it available via the B-CAN network to the Instrument Panel Node.

The Instrument Panel Node lights up the dedicated warning light and displays the insufficient brake fluid level message; if the warning light is faulty the relevant message is displayed.

Applies to: all engines; all production periods
