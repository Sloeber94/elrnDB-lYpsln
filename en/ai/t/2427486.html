The system is not working properly.

Applies to: all engines; all production periods

Results of the tests

1

CHECKING WITH DIAGNOSTIC EQUIPMENT

All OK

Problems met

Operation

Connect the Examiner to the diagnostic connector and check the following at the brake node

In errors ambient:

  • that there are no faults

In parameter mode

  • the plausibility of all the parameters.

In active diagnosis mode:

  • operation of ABS warning light

Continue to Step 2

Presence of errors at the vehicle speed sensors

Check the wiring for the wheel speed sensor concerned, making sure that there are no loose connections and that the sensor is correctly positioned

Presence of other faults

Continue according to the instructions for the diagnostic equipment

The warning light does not come on

Change the brake system control unit

2

CHECKING BRAKE HYDRAULIC SYSTEM

All OK

Problems met

Operation

Disconnect the ABS electrical connection and test the efficiency of the braking system with the aid of a service rig.

Continue to Step 3

Braking action not balanced

Overhaul the braking system

3

CHECK ON CORRECT OPERATION

All OK

Problems met

Operation

Check that the fault is no longer present

the test is essential, as the braking system is a safety feature of the car

End of diagnosis

Fault persists

Replace the brake system hydraulic unit
