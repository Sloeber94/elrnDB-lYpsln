K68 CONTROL PANEL ESP WARNING LIGHT ON

Applies to: all engines; all production periods

The brakes node sends the ABS warning light on message via the C-CAN to the Body Computer which makes it available via the B-CAN network to the instrument panel node.

If there are faults at the C-CAN, the control unit failure warning lights will light up. The CAN INFORMATION check is designed precisely for this purpose

Applies to: all engines; all production periods
