Applies to: all engines; all production periods

Before removing and refitting the switch, the following preliminary operations must be carried out:

Place the ignition key in the OFF position and extract it;

Disconnect the battery.

It is not possible to order a single lock barrel or to order barrels simply by using a part code. When ordering barrels, observe the special procedure set out in 5580E - Special accessories.

Applies to: all engines; all production periods

Refitting

2. Disconnect the electrical connection.
