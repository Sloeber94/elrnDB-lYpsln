P10 CENTRAL LOCKING / NOT WORKING

Applies to: all engines; all production periods

When the door lock is operated with the mechanical key or from inside, via the controls on the tunnel control panel, the central locking system does not work.

The door unlocking/locking request reaches the body computer node from the door nodes via the the B-CAN. The body computer node sends the command to the door nodes which unlock/lock the side doors and it directly controls the unlocking/locking of the boot.

Applies to: all engines; all production periods
