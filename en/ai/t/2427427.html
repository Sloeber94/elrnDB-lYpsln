Applies to: all engines; all production periods; only with equipment: ESP

The ASR HBA HH drive control system is included in the ESP vehicle stability control system and is not fitted individually on any of the vehicles. Therefore as far as this system is concerned, refer to Description and Operation 3350E vehicle direction control system vdc.
