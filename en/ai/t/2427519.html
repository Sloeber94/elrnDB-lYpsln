When the steering column switch unit ring nut is operated with the ignition ON, one of the main beam headlamps does not work

Applies to: all engines; all production periods

Results of the tests

1

CHECK ON INDIVIDUAL LIGHTS

All OK

Problems met

Operation

Check the condition of individual bulbs and light units.

Continue to Step 2

Bulbs damaged

Replace bulbs

Front right light cluster faulty

Repair or replace front lights cluster

Front left light cluster faulty

Repair or replace front lights cluster

2

DIPPED HEADLAMPS ELECTRICAL CIRCUIT CHECK

All OK

Problems met

Operation

Check, in order:

  • left or right main beam headlamp fuses;
  • connections between engine bay control unit and bulbs;
  • bulb earth: See E2012 MAIN BEAM HEADLAMPS

Continue to Step 3

Defective component

Replace the component involved (if a fuse is involved, search for the cause of the problem)

Defective component

Restore the connections

Defective component

Restore the earth to the bulbs See E2012 MAIN BEAM HEADLAMPS

3

CHECK ON CORRECT OPERATION

All OK

Problems met

Operation

Check that the fault is no longer present

End of diagnosis
