0510A10 cylinder compression - check for loose spark plugs or injectors

Applies to: engines: 1.2 8v, 1.2 16v, 1.4 16v; all production periods

Disconnect the electrical connections for the engine management control unit ( 1056B82 injection/ignition system e.c.u. (one) - r + r ).

Name

Connector

-

Engine management control unit

M10

Insert the test instrument into the seat of the spark plug.

Via the starter motor, make the engine execute a few revolutions while holding down the accelerator and clutch pedals.

Make sure that there are no leaks from the test instrument's connection.

Repeat the test on the remaining cylinders, making sure to reset the instrument each time.

Check that the cylinders' pressure readings do not differ excessively.

Connect the electrical connection for the engine management control unit ( 1056B82 injection/ignition system e.c.u. (one) - r + r ).
