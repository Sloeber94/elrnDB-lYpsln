Applies to: all engines; all production periods

The milometer either does not work or does not work properly whilst driving.

The speedometer works properly. If the speedometer is faulty, see Table K003.

Applies to: all engines; all production periods

Results of the tests

0

PRELIMINARY CHECK

All OK

Problems met

Operation

Check:

  • that the instrument panel light dimmer has not been selected.
  • That the mode button has not been pressed.
  • That there are no failure messages displayed

Continue to Step 1

The display shows other information

Restore the display conditions using the control panel

1

CHECK WITH DIAGNOSTIC EQUIPMENT

All OK

Problems met

Operation

Connect the Examiner to the diagnostic socket

Check that there are no faults in the instrument panel

Continue to Step 2

There are errors

Proceed in accordance with the instructions given by the diagnostic equipment

2

CHECK WITH DIAGNOSTIC EQUIPMENT

All OK

Problems met

Operation

Keeping the Examiner connected to the diagnostic socket, check the operation of the display in active diagnosis.

Continue to Step 3

Milometer not working

Replace instrument panel Op. 5560B11

3

ELECTRICAL CIRCUIT CHECK

All OK

Problems met

Operation

Check connections between instrument panel Body Computer and ABS control unit

Continue to Step 4

Faulty wiring

Restore/replace the wiring: See E4010 INSTRUMENT PANEL

4

CHECK WITH DIAGNOSTIC EQUIPMENT

All OK

Problems met

Operation

With the diagnostic equipment (Examiner or other instruments) connected, check the CAN information:

  • For inactive control units;
  • That there are no control unit errors;
  • That there are no control units with CAN line errors

Continue to Step 5

Presence of faults

Continue following the instructions for the diagnostic equipment

5

CHECK ON CORRECT OPERATION

All OK

Problems met

Operation

Check that the fault is no longer present

End of diagnosis
