When it is raining or after washing, there is water in the front of the passenger compartment.

Applies to: all engines; all production periods

Results of the tests

1

CHECK THAT THERE IS NO PENETRATION THROUGH THE WINDSCREEN

All OK

Problems met

Operation

Check that there is no penetration through the windscreen: in particular check the sealant ( See Test 7035A Check there is no penetration through the fixed windows (windscreen and rearscreen))

Continue to Step 2

Penetration through the windscreen

Eliminate penetration (Op. 7035A04)

2

ENGINE COMPARTMENT BULKHEAD DRAINAGE CHECK

All OK

Problems met

Operation

Check the drainage of the engine compartment bulkhead.

In particular, check for dirt, leaves etc.

Continue to Step 3

Dirt in drains

Clean the drains. If necessary refit correctly

3

ENGINE COMPARTMENT BULKHEAD CHECK

All OK

Problems met

Operation

Check the engine compartment bulkhead. In particular, ascertain:

  • The plugs are fitted;
  • The plugs are correctly fitted;
  • The rubber cable covers are fitted correctly;
  • the sealing is efficient
  • correct fitting

Continue to Step 4

Faults in the engine compartment bulkhead

Restore the engine compartment bulkhead fitting and fixings

4

CHECK ON CORRECT OPERATION

All OK

Problems met

Operation

Check that the fault is no longer present

End of diagnosis

Fault persists
