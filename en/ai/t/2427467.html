PRELIMINARY CHECKS

All OK

Problems met

Operation

Turn the ignition on and check that the CODE is working properly

Check:

  • that the inertia switch has not cut in;
  • that there is fuel in the tank
  • air intake circuit;
  • correct operation of the exhaust pipes.
  • that there are no leaks from the high- and low-pressure fuel pipes
  • that there is no petrol, water, paraffin or dirt in the diesel filter.

Continue to Step 1

CODE fault message present

Continue according to the instructions for the See table K52 CODE FAILURE WARNING LIGHT ON

Operation of inertia switch

Restore correct operation

No fuel

Put fuel in the tank

Air filter dirty or partly obstructed

Replace the filter element Op. 1048A14 air cleaner filtering element - replace.

Exhaust blocked

Repair the exhaust pipes

There are leaks

Eliminate the leaks

Presence of water, petrol, paraffin or dirt detected

Clean the tank and pipes and replace the diesel filter cartridge Op. 1044B20 fuel filter filtering element - replace
