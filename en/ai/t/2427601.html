P11 CENTRAL LOCKING / NOT WORKING WITH REMOTE CONTROL

Applies to: all engines; all production periods

When the door unlocking/locking command is given from the remote control, the central locking system does not work.

The Body Computer Node receives a signal from the remote control via the radio aerial. Having received the command, it sends the door unlocking/locking signal to the door nodes and directly controls the boot lock.

Applies to: all engines; all production periods
