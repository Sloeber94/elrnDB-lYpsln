The climate control is working properly, but there is an unpleasant smell in the passenger compartment

Applies to: all engines; all production periods

Results of the tests

0

PRELIMINARY CHECKS

All OK

Problems met

Operation

First check that the unpleasant smells are not coming from the outside: they can be eliminated straight away by switching on the recirculation function

Continue to Step 1

Recirculation not working

Continue according to the instructions for the See table L16 CLIMATE CONTROL RECIRCULATION NOT WORKING

1

CHECKING POLLEN FILTER

All OK

Problems met

Operation

Check the condition of the pollen filter

The pollen filter should be replaced at least once a year.

Continue to Step 2

Filter obstructed

Replace the filter element ( Op. 5010B09 purifying filter (antipollen) filter element - replace)

2

AIR SUPPLY DUCTS CHECK

All OK

Problems met

Operation

Check the air supply ducts: they should not be obstructed with dirt or foul smelling substances

Continue to Step 3

Ducts obstructed

Wash the ducts

3

CHECKING HEATER RADIATOR

All OK

Problems met

Operation

Check the heater radiator: the outer fins should not be obstructed with dirt or other substances

Continue to Step 4

Radiator dirty or obstructed

Clean or replace the radiator (Op. 5040C50)

4

CHECK ON CORRECT OPERATION

All OK

Problems met

Operation

Check that the fault is no longer present

End of diagnosis

Fault persists

Search for the fault starting from another symptom'
