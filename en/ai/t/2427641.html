EXHAUST SYSTEM LEAKS CHECK

All OK

Problems met

Operation

Check the exhaust system, visually and by listening, from the cylinder head outlet to the downstream Lambda sensor.

Check that there are no leaks

Continue to Step 2

There are leaks

Restore the correct seal for the exhaust system, if necessary, replace the components involved.

Continue to Step 5

2

ROAD TEST TO CHECK MIXTURE STRENGTH

All OK

Problems met

Operation

Road test the vehicle and check the mixture strength in the 1st and 2nd closed loops using the diagnostic equipment.

Check that the activation is correct

Continue to Step 3

The 1st closed loop activation is not correct

Continue according to the instructions for the See table Z56 UPSTREAM LAMBDA SENSOR SIGNAL ERROR

The 2nd closed loop activation is not correct

Continue according to the instructions for the See table Z58 DOWNSTREAM LAMBDA SENSOR SIGNAL ERROR

3

CHECKING INTAKE AND EXHAUST SYSTEM SEAL

All OK

Problems met

Operation

Check the exhaust system visually and by listening, to check that there are no leaks from the cylinder head outlet to the upstream lambda sensor

Continue to Step 4

Seal not correct

Restore the correct seal for the system, if necessary, replace the components involved.

Continue to Step 5

4

REPLACING THE CATALYZER

All OK

Problems met

Operation

Replace the catalyzer Op. 1080B62 catalytic converter - r + r

Continue to Step 5

5

ERROR CANCELLING AND CHECKING

Problems met

Operation

Use a tester to cancel the errors in the control unit.

The fault persists, it is the first time that this step has been reached and the catalyzer has not yet been replaced

Continue to Step 0

The fault persists, but it is the second time that this step has been reached or the catalyzer has already been replaced
