Applies to: all engines; all production periods

When the brake pedal is pressed, with the ignition on, the centre brake light ('third brake light') does not work. If the side stop lights are not working either, see Table I015

Applies to: all engines; all production periods

Results of the tests

1

CHECK ON INDIVIDUAL LIGHTS

All OK

Problems met

Operation

Check the condition of the third brake light

Continue to Step 2

Third brake light not working

Change third brake light

2

BRAKE LIGHTS SWITCH CHECK

All OK

Problems met

Operation

Check that the brake light switch is correctly fastened and working properly

Continue to Step 3

Brake light switch faulty

Renew or replace the brake light switch

3

BRAKE LIGHTS ELECTRICAL CIRCUIT CHECK

All OK

Problems met

Operation

Check, in order:

  • third brake light fuse;
  • connections between DASHBOARD control unit and brake pedal switch;
  • connections between DASHBOARD control unit and bulb;
  • bulb earth See E2021 BRAKE LIGHTS

Continue to Step 4

Defective component

Replace the component involved (if a fuse is involved, search for the cause of the problem)

Connections broken

Restore the connections: See E2021 BRAKE LIGHTS

Faulty earth

Restore the earth contact See E2021 BRAKE LIGHTS

4

CHECKING FACIA CONTROL UNIT

All OK

Problems met

Operation

Check the continuity of the facia control unit internal circuit See E2021 BRAKE LIGHTS

Continue to Step 5

Facia control unit circuit broken

Change the facia junction unit

5

CHECK ON CORRECT OPERATION

All OK

Problems met

Operation

Check that the fault is no longer present

End of diagnosis
