R01 AIRBAG FAILURE WARNING LIGHT ON

Applies to: all engines; all production periods

During starting, the air bag failure warning light comes on and remains on for more than 4 seconds (after the control unit initial test, the warning light should go out)

In the case of a reasonably serious impact which has caused the activation of the complete system (Air Bag and Side Bag), the warning light stays on. The control unit memory cannot be cleared, so the control unit must always be replaced. If, on the other hand, only the Side Bags have been activated, the memory can be cancelled using the diagnostic equipment (Examiner or other instruments) twice. In this case the 'Air Bag Failure' warning light goes out. The control unit only has to be replaced if it is activated a third time.
