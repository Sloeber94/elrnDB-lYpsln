Applies to: engines: 1.2 16v, 1.4 16v; all production periods

This test requires the spark gap kit (No. 1806369000).

Make sure that the ignition key is in the OFF position.

Remove the H.T. coil from its housing.

Insert the spark gap (SP-02) between the H.T. outputand earth

Make sure that the rubber protective boots for the cables are correctly fitted

Disconnect the electrical connections from the injectors.

Start up the engine and check that there is a spark between the spark gap points

Repeat the test for the other coils.

Cancel the injector errors using the diagnostic equipment

The coils can be tested by activating the 'Active Diagnosis' for the coils using the Examiner and listening to the clicking of the H.T. sparks operated by the diagnostic equipment.
