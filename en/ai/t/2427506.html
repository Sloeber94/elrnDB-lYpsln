Applies to: all engines; all production periods

When the steering column switch unit ring nut is operated with the ignition ON, the dipped headlamps do not work

Applies to: all engines; all production periods

Results of the tests

1

CHECKING WITH DIAGNOSTIC EQUIPMENT

All OK

Problems met

Operation

Connect the Examiner to the diagnostic socket

check

  • that there are no faults in the Body Computer
  • the operation of the lights in active diagnosis.

Continue to Step 3

Dipped headlamps relay error (in dashboard control unit)

Check the dipped headlamps relay.

Continue to Step 3

Lights not activated

Check the individual lights.

Continue to Step 2

2

CHECK ON INDIVIDUAL LIGHTS

All OK

Problems met

Operation

Check the condition of individual bulbs and light units.

Continue to Step 3

Bulbs damaged

Replace bulbs

Bulbs damaged

Repair or replace front lights cluster

Bulbs damaged

Repair or replace front lights cluster

3

DIPPED HEADLAMPS ELECTRICAL CIRCUIT CHECK

All OK

Problems met

Operation

Check, in order:

  • right and left dipped headlamp fuses;
  • dipped headlamps relay
  • connections between steering column switch unit and Body Computer;
  • connections between Body Computer and dashboard control unit;
  • connections between dashboard control unit and bulbs;
  • bulb earth: wiring diagram See E2011 DIPPED HEADLAMPS

Continue to Step 4

Defective component

Replace the component involved (if a fuse is involved, search for the cause of the problem)

Connections broken

Restore the connections: wiring diagram See E2011 DIPPED HEADLAMPS

Lamps earth defective

Restore the bulb earth: wiring diagram See E2011 DIPPED HEADLAMPS

4

CHECK ON STEERING COLUMN SWITCH UNIT

All OK

Problems met

Operation

Check that the stalk unit is working properly; in particular check the side lights switch

Continue to Step 5

Stalk unit not working properly

Replace the stalk unit

5

CHECK ON BODY COMPUTER

All OK

Problems met

Operation

Check that the Body Computer is supplied properly

Check that when an earth signal from stalk unit to Body is activated, an earth signal is emitted from the Body to drive the dipped beam headlamps relay: See E2011 DIPPED HEADLAMPS

Continue to Step 6

Body Computer supply incorrect

Restore the correct supply See E2011 DIPPED HEADLAMPS

Body Computer defective

Replace the Body Computer

6

CHECK ON CORRECT OPERATION

All OK

Problems met

Operation

Check that the fault is no longer present

End of diagnosis
