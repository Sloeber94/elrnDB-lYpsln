Applies to: all engines; all production periods

When the steering column switch unit ring nut is operated with the ignition ON, one of the dipped headlamps does not work.

Applies to: all engines; all production periods

Results of the tests

1

CHECK ON INDIVIDUAL LIGHTS

All OK

Problems met

Operation

Check the condition of individual bulbs and light units.

Continue to Step 3

Bulbs damaged

Replace bulbs

Front right light cluster faulty

Repair or replace front lights cluster

Front left light cluster faulty

Repair or replace front lights cluster

2

CHECKING BRAKE HYDRAULIC SYSTEM

All OK

Problems met

Operation

Check, in order:

  • left or right dipped headlamp fuses;
  • connections between dashboard control unit and bulbs;
  • bulb earth: See E2011 DIPPED HEADLAMPS

Continue to Step 3

Defective component

Replace the component involved (if a fuse is involved, search for the cause of the problem)

Defective component

Restore the connections: See E2011 DIPPED HEADLAMPS

Defective component

Restore the earth to the bulbs : See E2011 DIPPED HEADLAMPS

3

CHECKING FACIA CONTROL UNIT

All OK

Problems met

Operation

Check the continuity of the facia control unit internal circuit See E2021 BRAKE LIGHTS

Continue to Step 4

Facia control unit circuit broken

Change the facia junction unit

4

CHECK ON CORRECT OPERATION

All OK

Problems met

Operation

Check that the fault is no longer present

End of diagnosis
