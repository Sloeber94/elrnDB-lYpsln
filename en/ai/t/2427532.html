Applies to: all engines; all production periods

With the ignition ON, the milometer cannot be zeroed using the TRIP button on the right steering column switch unit lever.

Applies to: all engines; all production periods

Results of the tests

1

CHECK WITH DIAGNOSTIC EQUIPMENT

All OK

Problems met

Operation

Connect the Examiner to the diagnostic socket

Check that there are no faults in the instrument panel

Continue to Step 2

There are errors

Proceed in accordance with the instructions given by the diagnostic equipment

2

ELECTRICAL CIRCUIT CHECK

All OK

Problems met

Operation

Check:

  • Connections between right steering column switch unit lever and instrument panel
  • Connections between right steering column switch unit lever and earth;
  • Steering column switch unit right lever power supply;
  • Steering column switch unit right lever earth See E4010 INSTRUMENT PANEL

Continue to Step 3

Connections defective, earth or supply defective

Restore the correct connections, if necessary, replace the wiring : See E4010 INSTRUMENT PANEL

3

CHECK ON STEERING COLUMN SWITCH UNIT

All OK

Problems met

Operation

Check that the TRIP button on the right steering column switch unit lever is working properly See E4010 INSTRUMENT PANEL

Continue to Step 4

Right lever defective

Replace the steering column switch unit Op. 5550A12 complete stalk unit - r+r for versions with air bag

4

CHECK ON CORRECT OPERATION

All OK

Problems met

Operation

Check that the fault is no longer present

End of diagnosis
